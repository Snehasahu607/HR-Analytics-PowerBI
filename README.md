# HR Analytics Dashboard – Power BI

## 📊 Project Overview

This project is an interactive **HR Analytics Dashboard** built using **Microsoft Power BI** to analyze employee attrition and workforce trends.

The dashboard helps HR teams understand employee attrition based on factors such as **age, gender, education, salary, job role, department, and years at the company**.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- HR Analytics

## 📁 Dataset

The project uses the **IBM HR Analytics Employee Attrition dataset**, containing employee-level information such as:

- Age
- Gender
- Education
- Department
- Job Role
- Monthly Income
- Years at Company
- Job Satisfaction
- Attrition

## 📌 Key KPIs

The dashboard provides the following key metrics:

- **Total Employees:** 1,470
- **Attrition:** 238
- **Attrition Rate:** 16.2%
- **Average Age:** 37
- **Average Salary:** 6.5K
- **Average Years at Company:** 7.0

## 📈 Dashboard Analysis

The dashboard analyzes:

1. Attrition by Gender
2. Attrition by Education
3. Attrition by Age Group
4. Attrition by Salary Slab
5. Attrition by Years at Company
6. Attrition by Job Role
7. Employee distribution across departments

## 🔄 Data Preparation

**Power Query** was used for data preparation and transformation, including:

- Checking data types
- Cleaning and organizing columns
- Creating meaningful categories
- Preparing the dataset for visualization

## 🧮 DAX

DAX measures were used to calculate important HR metrics such as:

- Total Employees
- Attrition Count
- Attrition Rate
- Average Age
- Average Salary
- Average Years at Company

## 💡 Key Insights

The dashboard helps identify:

- Overall employee attrition level
- Employee groups with higher attrition
- Relationship between salary and attrition
- Job roles with comparatively higher attrition
- Attrition patterns across different age groups
- Workforce distribution across departments

## 🎯 Business Objective

The main objective is to help HR teams identify **attrition patterns and potential risk areas** so that appropriate employee retention strategies can be planned.
